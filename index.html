АРХИМЕДОстрова Познания

Углублённое изучение предметов и подготовка к олимпиадам. Математика, русский язык, физика, химия, информатика — 1–9 класс. Школьная программа берётся глубже учебника, а приёмы разбираются на задачах Всероссийской олимпиады.

Открыть приложение → Работает в браузере и ставится на телефон как приложение. Прогресс хранится на устройстве.

Для родителя — отдельный кабинет: отчёт по коду ребёнка.

Как учим

Не «ещё один сборник задач»: путь от школьной темы до олимпиадного приёма проходится по шагам.

Сначала объясняем Приём разбирается по кадрам, у каждого — своя сцена и своя анимация, а не общий шаблон.
Потом проверяем понимание Короткий вопрос после объяснения: не заучил ли ученик ответ вместо приёма.
И только затем даём решать Задачи с подсказками-лестницей: сначала намёк, потом ход, и лишь в конце полное решение.
Дальше — олимпиадный уровень Разборы задач ВсОШ и Сириуса, ловушки и типовые ошибки, проверочные работы формата МЦКО.

Как устроено

Чистый JavaScript без сборщика: скрипты подключаются тегами с меткой версии ?v=NNN, она же в имени кэша сервис-воркера — так браузер не отдаёт старый код. Python нужен только для выкладки, шлюза (связка «родитель — ученик», голос) и проверок.

У проекта своя система машинных проверок: геометрия кадра, раскладка на 320 и 390 px, контраст и цели касания, отклик тренажёров, инварианты заданий. Правило простое — выкладывать только на зелёных проверках, но смотреть на результат и глазами: геометрия ловит «налезло», а не «не то, о чём просили».

Запустить у себя

git clone https://github.com/s5hyhbpftv-alt/arhimed.git
cd arhimed/MVP && python3 -m http.server 8123
# → http://127.0.0.1:8123/

Так работает всё, кроме кабинета родителя и голоса: им нужен шлюз шлюз_сервер.py, а голосу — ещё и ключ Яндекса.
