# АРХИМЕД · MVP-приложение (единая кодовая база)

Единое веб-приложение по ТЗ_MVP.md: игровая вселенная олимпиадной подготовки для школьников 10–17 лет.
Собирает разрозненные прототипы в один продукт: **профиль → «Путь» (карта островов) → задачи (микро-петля) → награда → кабинет родителя**.

## Запуск
Любым статическим сервером из корня проекта (SW не требуется): `python3 -m http.server 8123`
→ открыть `http://localhost:8123/MVP/`. Работает и напрямую по `file://`, и с телефона.

## Архитектура (слои)
```
MVP/
├─ index.html          — оболочка SPA (экраны, стили, нижняя навигация)
├─ data/tasks.js       — единый банк задач (59 шт., автособран из тренажёров)
└─ js/
   ├─ core.js          — слой данных: профиль, прогресс, валюта, история, лимит дня;
   │                     конверсия единиц; хранилище localStorage (готово к замене на API)
   ├─ engine.js        — движок микро-петли: рендер задачи, подсказки-лестница (0/5/10 ⭐),
   │                     проверка ответа (choice/число+единицы), «Решение Архимеда», награда
   ├─ app.js           — экраны и маршрутизация: онбординг, Путь, Остров, Банк задач
   └─ dashboard.js     — родительский кабинет: прогноз готовности к ВсОШ (эвристика),
                          слабые темы, прогресс по темам, лимит времени, лента активности
```

## Что внутри (Milestone 1)
- **Онбординг**: имя, класс, уровень, цвет хитона → профиль в `arhimed_mvp_v1`.
- **Путь**: 4 острова (Сиракузы-математика · 26, Ньютон-физика · 26, Лавуазье-химия · 7,
  Информатика-кодирование/алгоритмы/логика · 12), всего 71 задача,
  прогресс по темам, кнопка «Продолжить» (адаптивный порядок).
- **Микро-петля задачи**: сюжет → вопрос → подсказки (первая бесплатно, далее за ⭐)
  → проверка (число с единицами или выбор) → фидбек → «Решение Архимеда» → «Дальше».
- **Экономика**: ⭐ очки за решение (зависит от сложности и числа подсказок), 🔥 серия, ранги.
- **Родитель**: прогноз готовности к школьному этапу ВсОШ, слабые темы, лимит минут на день,
  лента последних решений, сброс.

## Голосовой помощник «Архимед» — всплывающий аватар (assistant.js + voice.js)
- **Нарисованный аватар Архимеда (SVG)**: круглый мудрец с бородой, хитоном и оливковым венком —
  всплывает в правом нижнем углу на всех экранах. Когда Архимед говорит — «рот» открывается и аватар
  покачивается; в покое — лёгкое «дыхание» (idle).
- **Речевой пузырь** над аватаром показывает текст озвучки (живые субтитры).
- **Панель по клику**: «🗣 Прочитай контекст» (задача/шаг урока — определяется по текущему экрану),
  «💡 Подсказка 1», «⏩ Дальше», «📜 Решение», «👋 Привет», кнопка микрофона 🎙, голос вкл/выкл, темп ±.
- **Озвучка (TTS, ru-RU)**: русский голос, темп 0.5–1.6x, настройки в профиле; команды микрофона:
  «объясни задачу», «подсказка 1/2/3», «дальше», «назад», «решение», «стоп», «темп быстрее/медленнее», «привет».
- В headless проверены все код-пути и отрисовка аватара (0 ошибок JS); реальное звучание и распознавание
  требуют браузера с голосами и разрешением на микрофон.

## ☁ Yandex SpeechKit (голоса Яндекса)
Третий источник в панели Архимеда — **☁ SpeechKit**: женские/мужские нейроголоса Яндекса (Алёна, Филипп,
Джейн, Омаж) через облачный API. Ключ хранится **на сервере** (браузер его не видит):
- положите API-ключ SpeechKit в файл `ключ_яндекса.txt` в корне проекта (первая строка) или задайте
  переменную `YANDEX_API_KEY`;
- ключ: `console.cloud.yandex.ru` → SpeechKit → создать сервисный аккаунт с ролью `ai.speechkit-tts.user`
  → API-ключ (нужен биллинг);
- переключение: в панели нажмите «🎛 Система» → «🤖 Piper» → «☁ SpeechKit»; при выборе SpeechKit появится
  список голосов. Эндпоинт сервера: `GET /sk?text=…&voice=alena` (audio/ogg).
- без ключа сервер отвечает 503 и приложение показывает подсказку.

## 🎙 Голосовой агент (agent.js)
Архимед — не только команды: скажите вопрос голосом (кнопка 🎙), и агент **ответит по смыслу**:
- объясняет олимпиадные приёмы и термины (Дирихле, инвариант, чётность, «оценка и пример», перевёртыши,
  турниры, делимость, взвешивания, комбинаторика, графы…);
- отвечает про текущую задачу/урок («объясни задачу», «какая подсказка», «как решить» после верного ответа);
- считает арифметику словами («сколько будет 12 плюс 7»);
- отвечает на приветствие и поддерживает простой диалог; непонятное — вежливо переспрашивает.
Мозг агента — офлайн (agent.js), без внешних API; голос ответа — выбранный источник (система/Piper/SpeechKit).
«Голосовой агент» уровня LLM-диалога требует API-ключа провайдера — при наличии подключим.

## Источник голоса: только SpeechKit
По решению продукта помощник говорит **только голосом Yandex SpeechKit** (переключатели «система/Piper»
убраны). Если SpeechKit недоступен (нет/неверен ключ, сервер не запущен) — включается **тихий системный
запасной голос** с пояснением в панели (страховка от полной тишины, не выбор пользователя).
- Панель Архимеда: список голосов SpeechKit (Алёна, Филипп, Джейн, Омаж) + кнопка «▶ Проверить»;
- Подпись показывает состояние: «☁ SpeechKit „Алёна"» / «… не настроен — запасной системный голос»;
- Рабочий ключ (AQVN…, роль ai.speechkit-tts.user) — в файл `ключ_яндекса.txt` или `YANDEX_API_KEY`;
  после проверки подпись сменится на активную, запасной голос отключится.

## 🎙 Живой голосовой агент (Yandex Realtime, встроен в приложение)
Кнопка **«🎙 Живой агент»** в панели Архимеда открывает живой диалог: браузерный микрофон →
сервер-ретранслятор (`агент_сервер.py`, порт 8125) → **Yandex Realtime** (LLM + речь) → голос в динамики.
- **Агент здоровается по имени**: при старте сессии сервер вставляет реплику с именем ребёнка
  («Привет! Меня зовут {имя}…») — проверено: агент отвечает «Привет, Лена! Давай решим задачку» + аудио;
- Настройки агента — ваши: каталог `b1gls…`, модель `speech-realtime-260528/latest`,
  **PROMPT_ID `aipsdas460c1epis87m1`** (это ID голосового агента, не ключ), ключ из `ключ_яндекса.txt`;
- Запуск: `python3 агент_сервер.py` (8125) — приложение подключается к `ws://<хост>:8125/agent?name=…`;
- Платно (Yandex по вашей учётке). Headless-проверка аудио с микрофоном невозможна — соединение,
  приветствие по имени и аудио-ответ подтверждены на уровне сервера.
