## 3. Какие шаги рассуждения показаны

Разбор есть у каждого задания и напечатан блоками одного устройства:

* **Шаг 1 … Шаг N** — пронумерованный ход, по одной мысли в шаге
  (7–8 шагов в заданиях 1–2 и 7, 5–6 шагов в остальных);
* **Вывод** — ответ одной фразой;
* **Второй способ** — перебор против рассуждения и что короче
  (задания 1, 2, 3, 4, 5, 6, 7, 8 — во всех восьми);
* **Частая ошибка** — как думают и где именно ломается логика
  (во всех восьми; например: «считать ложные фразы вместо лжецов»,
  «прочитать „кроме двух“ как „двое“ и сложить 2 + 2 + 2 = 6»,
  «начать с подсказки про Барсика и получить два варианта»);
* **Как проверить себя** — подставить ответ обратно в условие и убедиться,
  что сходятся все подсказки (во всех восьми).

Ход решения в каждом задании:

1. три версии по очереди (лжец М / лжец Т / лжец С) → противоречие → вывод;
2. три версии виновника → противоречие → вывод; второй способ через
   противоположные фразы;
3. отсечение по подсказке «Соня правее Мишутки» → второй дом → третий дом
   для Сони; второй способ — перебор шести расстановок;
4. Мишутка не в среду и не в четверг → вторник; Тимоша позже; Соня не в
   четверг отсекает лишний вариант;
5. уравнение по цветам: 3·(n − 2) = n → n = 3; второй способ — подбор;
6. пара «Тимоша на год младше Сони» → две пары → «Мишутка не самый старший»
   убирает первую;
7. наклейка «смесь» неверна → содержимое однородно → один предмет
   достраивает остальные две коробки; объяснено, почему коробка «шишки»
   не годится;
8. красная не снизу (синей некуда) → средняя → синяя снизу → зелёная сверху.
