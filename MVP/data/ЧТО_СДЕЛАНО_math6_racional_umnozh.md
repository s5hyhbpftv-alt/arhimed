## Содержание — 8 заданий + проверка + 3 задачи

Восемь заданий с интерактивным ответом (по три варианта):

1. умножение двух отрицательных: (−4) · (−6);
2. умножение с разными знаками: (−3) · 7;
3. правило знаков при умножении — знак результата без счёта;
4. деление отрицательных: (−42) : (−6);
5. деление с разными знаками: 36 : (−4);
6. цепочка умножений со знаками: (−2) · (−3) · (−1) · 5;
7. задача про изменение температуры: −2° каждый час за 5 часов;
8. задача про долг, разделённый на равные части: −72 на 6 частей.

Проверка — вопрос с ловушкой: знак произведения (−7) · (−3) · (−2).
Задачи: изменение уровня воды (−4 см за 6 часов → −24), ловушка Мишутки
((−8) · (−5) = −40 — знак потерян), долг 96 рублей на 8 частей → −12.

## Усиленное объяснение (требование владельца)

* **Пошаговый разбор в каждом из восьми заданий** — ровно четыре шага. Для
  первого задания формулировка владельца дословно: «Шаг 1. Смотрим на знаки:
  минус на минус. Шаг 2. По правилу получаем плюс. Шаг 3. Умножаем модули:
  4 · 6 = 24. Шаг 4. Проверка: 24 : (−6) = −4 — вернулись к исходному».
* **Таблица знаков** — отдельным кадром, и на умножение, и на деление
  (plus·plus, plus·minus, minus·plus, minus·minus). Клетки «минус на минус —
  плюс» отмечены золотом и галочкой, нарисованной путём.
* **«Частая ошибка» в каждом задании**: правильно посчитать модули и потерять
  знак; думать, что минус на минус даёт минус; складывать вместо умножения;
  решать знак по «большему числу».
* **«Как проверить себя» в каждом задании** — обратным действием: умножение
  проверяем делением, деление умножением (24 : (−6) = −4; (−21) : 7 = −3;
  7 · (−6) = −42; (−12) · 6 = −72 и т. д.).
* **«Второй способ» в каждом задании** — через смысл, без правила: «убрать
  долг 4 рубля шесть раз», «долг 3 рубля повторили 7 раз», «долг по 6 пять раз».
* **Блок «почему минус на минус даёт плюс»** — на понятном примере: пять
  долгов по 6 — это −30; «убрать» эти долги — значит прибавить 30, поэтому
  (−5) · (−6) = +30. Плюс отдельный кадр «второй способ: долг по 6 пять раз»
  с суммой (−6) + (−6) + (−6) + (−6) + (−6) = −30.
