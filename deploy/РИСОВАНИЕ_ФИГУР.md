# Как рисуются фигуры в уроках АРХИМЕД

Документ собран из трёх источников: скил проекта `arhimed-drawing` (палитра,
манера, свет, посадка), справочник `svg-creator/references/advanced-techniques.md`
(пятизонное освещение, пара теней) и наших собственных замеров и ошибок.
Относится к объёмным телам, плоским фигурам и развёрткам в кадрах уроков.

## 1. Три правила, которые нельзя нарушать

1. **Одна манера на кадр.** Комисная манера (обводка + плоские заливки)
   и интерфейсная (без обводки, кегли по шкале) в одном кадре не смешиваются.
   Геометрические тела в уроках рисуем комиксной манерой: у них есть обводка.
2. **Только код.** Ни одного растрового файла: тела — это SVG-полигоны,
   эллипсы и пути. Эмодзи в рисунке — дефект.
3. **Тело стоит на месте.** У каждого объёмного тела есть тень на «полу»,
   иначе оно висит в воздухе.

## 2. Палитра и обводка

| Что | Значение |
|---|---|
| Обводка тел | `#33291e`, толщина 1,6–2,2 |
| Обводка мелких деталей | тот же тон, 1,2–1,6 |
| Свет | сверху-слева, тёплый; тени внизу-справа, `opacity` 0.22–0.40 |
| Цвет тени | тёмно-синий `#0b1c2a` (отбрасываемая) и тёмно-тёплый `#231a12` (контактная) |
| Золото тел | `#fff3ce` → `#ffe08f` → `#f0c24c` → `#b9821a` |
| Сталь и вода | `#f2fbff` → `#c3e5f7` → `#5fadd8` → `#2f6b93` |
| Зелень | `#f0fdf6` → `#c4ecd6` → `#6db894` → `#3d7a5c` |
| Бумага развёртки | `#fbf8ef` → `#ece4cf` → `#d5caae`, подписи тушью `#1e3128` |

Чёрный и чистый белый не используем: тень — тёмно-синяя, свет — тёплый.

## 3. Постановка тела: две тени, а не одна

Одна размытая копия фигуры читается как второй предмет. Нужны **две** тени
на полу (рецепт из справочника, проверен на кадре 1 урока 996):

```xml
<filter id="отброс" color-interpolation-filters="linearRGB">
  <feGaussianBlur in="SourceAlpha" stdDeviation="6" result="р"/>
  <feOffset in="р" dx="5" dy="7" result="с"/>
  <feFlood flood-color="#0b1c2a" flood-opacity="0.22" result="ц"/>
  <feComposite in="ц" in2="с" operator="in"/>
</filter>
<filter id="контакт" color-interpolation-filters="linearRGB">
  <feGaussianBlur in="SourceAlpha" stdDeviation="1.6" result="р"/>
  <feOffset in="р" dx="0" dy="1" result="с"/>
  <feFlood flood-color="#231a12" flood-opacity="0.40" result="ц"/>
  <feComposite in="ц" in2="с" operator="in"/>
</filter>
```

Порядок в группе тела: **отбрасываемая тень → контактная тень → дальние грани
→ ближние грани → блик и световые кромки**. Фильтр тени не должен заканчиваться
`feMerge` с `SourceGraphic`: тогда рядом с телом появляется его резкая копия
(эта ошибка была в кадре 1 и стоила переделки).

## 4. Пятизонное освещение грани

У каждой видимой грани своя роль, и её задаёт градиент в 4 ступени с
`color-interpolation="linearRGB"`:

1. **блик** — светлая полоса по верхнему ребру передней грани;
2. **светлая зона** — верхняя грань (самая светлая);
3. **полутон** — передняя грань (истинный цвет предмета);
4. **тень формы** — боковая грань (холоднее и темнее, но не чёрная);
5. **отражённый свет** — тонкая тёплая линия `rgba(255,238,200,.28)` по нижнему
   ребру передней грани.

Плюс световая кромка по переднему левому ребру: `rgba(255,250,230,.5)`, ширина 1,6.

## 5. Аксонометрия: как строится объёмное тело

- **Три видимые грани**: передняя (прямоугольник), верхняя (параллелограмм),
  боковая (параллелограмм). Больше не рисуем — остальное скрыто.
- **Одно направление глубины** на весь кадр: глубина уходит **вправо-вверх**
  на `гл` единиц (у нас `гл ≈ 0.38 · ширины`). Менять направление между
  предметами в одном кадре нельзя: они окажутся в разных пространствах.
- **Смещение по глубине одинаковое** у всех тел кадра, иначе одно стоит ближе.
- Передняя грань — прямоугольник со сторонами `ш × в`; верхняя и боковая
  строятся сдвигом на `гл` по обеим осям:

```
перед:  (x, y) (x+ш, y) (x+ш, y-в) (x, y-в)
верх:   (x, y-в) (x+ш, y-в) (x+ш+гл, y-в-гл) (x+гл, y-в-гл)
бок:    (x+ш, y-в) (x+ш, y) (x+ш+гл, y-гл) (x+ш+гл, y-в-гл)
```

- **Пирамида**: основание — ромб (`перед`, `право`, `зад`, `лево`), вершина
  над центром ромба, видны две передние грани, задние рёбра штриховые.
  Плоский треугольник с косым четырёхугольником рядом — не пирамида
  (эта ошибка была в кадрах 1 и 7 урока 996).
- **Цилиндр**: два эллипса и боковая поверхность; верхний эллипс виден целиком,
  нижний — дугой. Ось симметрии одна, эллипсы одного радиуса.

## 6. Плоские фигуры и развёртки

- Клетки развёртки рисуем **соединёнными**: общее ребро соседних клеток и есть
  линия сгиба. Зазоры между клетками рассыпают фигуру (эта ошибка была в кадрах
  5 и 6 урока 996).
- Линия сгиба — штриховая `#33291e` или `ТУШЬ`, толщина 1,4–1,6.
- Подписи на светлой бумаге — только тушью `#1e3128`. Золото на бумаге даёт
  контраст около 1,3:1 и не читается (эта ошибка была в кадрах 4, 6 и 10).
- **Развёртка куба обязана сворачиваться.** Из шести квадратов складывается
  не любая фигура: у куба ровно 11 развёрток. Проверяем не глазом, а расчётом —
  перекатыванием куба по клеткам:

```python
def сворачивается(клетки):
    клетки = set(клетки); старт = next(iter(клетки))
    состояние = {старт: ((0,0,1),(1,0,0),(0,1,0))}   # верх, восток, юг
    очередь, грани = [старт], set()
    while очередь:
        к = очередь.pop(); up, e, n = состояние[к]
        грани.add(tuple(-x for x in up))             # грань на столе
        for дк, др, ф in ((1,0,'в'),(-1,0,'з'),(0,1,'ю'),(0,-1,'с')):
            с = (к[0]+дк, к[1]+др)
            if с not in клетки or с in состояние: continue
            if   ф == 'в': н = (tuple(-x for x in e), up, n)
            elif ф == 'з': н = (e, tuple(-x for x in up), n)
            elif ф == 'ю': н = (tuple(-x for x in n), e, up)
            else:          н = (n, e, tuple(-x for x in up))
            состояние[с] = н; очередь.append(с)
    return len(состояние) == len(клетки) and len(грани) == 6
```

  Так была найдена фигура «лестница», которая в куб не сворачивается, хотя
  состоит из шести квадратов.

## 7. Размеры фигур: считаем, а не рисуем «похоже»

- Развёртка параллелепипеда `a × b × c`: в ряду четыре боковые грани
  с размерами `b×c, a×c, b×c, a×c`, сверху и снизу — `a×b`. Каждая пара
  противоположных граней равна, и это должно быть **видно**.
- Площадь развёртки равна площади поверхности: куб — `6·a·a`,
  параллелепипед — `2·(ab + bc + ac)`. Полезно разбить грани на единичные
  квадраты и пересчитать их: у куба с ребром 3 их 54.

## 8. Обязательная проверка

1. `node --check <файл урока>` — синтаксис.
2. `PYTHONPATH=.py-libs python3 qa_layout.py <id>` — покадровая проверка:
   обрезка содержимого, выход за `viewBox` (SVG такое просто не рисует),
   наложения подписей, кегли вне шкалы, число анимаций, ноль анимаций
   при `prefers-reduced-motion`, совпадение числа кадров и шагов объяснения.
3. **Снимок и взгляд.** Инструмент не видит «некрасиво» и «неправильная
   фигура»: неверную развёртку и плоскую пирамиду нашёл владелец глазами.
   Порядок: лист всех кадров → крупный план каждого кадра → правки одним пакетом.
4. Приёмка кадра: тела стоят на тени, ничего не обрезано, подписи читаются,
   фигура математически верна (развёртка сворачивается, размеры сходятся).
