## История

В старой типографии есть **мастерская шифров**. Здесь придумывают два хитрых устройства: **числовую машину** (какое выражение из цифр 1–9 даст максимум) и **шифровальный станок** (как заменить буквы числами, чтобы код вышел самым коротким). Настрой оба — и типография заработает.

## Дело 1. Числовая машина (9 баллов)

Дано выражение:

```
1 ◦ 2 ◦ 3 ◦ 4 ◦ 5 ◦ 6 ◦ 7 ◦ 8 ◦ 9
```

Нужно расставить **ровно по два** знака каждого действия: **+**, **−**, **∗** (умножение), **/** (деление) — так, чтобы значение выражения было **как можно больше**.

Правила вычисления: сначала все умножения и деления **слева направо**, затем сложения и вычитания тоже слева направо. Скобки ставить нельзя.

**Ответ:** `1 − 2/3 − 4/5 + 6 + 7∗8∗9`.

**Как рассуждать:**
1. Хочется перемножить **самые большие** числа — их произведение даёт больше всего: `7∗8∗9`.
2. В выражении должны быть и вычитаемые слагаемые — их выгодно сделать **как можно меньше по модулю**, поэтому используем **деление**: `−2/3`, `−3/4`, `−4/5`, `−5/6`.
3. Самое маленькое по модулю — `−2/3`, следующее, не задевающее уже использованные цифры 2 и 3, — `−4/5`.
4. Оставшаяся цифра 6 идёт со знаком **+**.

**Критерий:** 9 баллов за верную расстановку (чем меньше значение, тем меньше баллов).

**Интересный факт.** Выражение вычисляется **в два прохода** — сначала «сильные» действия, потом «слабые». Именно так работают приоритеты операций в любом языке программирования: `2 + 3 * 4` — это 14, а не 20.

## Дело 2. Шифровальный станок (9 баллов)

Станок заменяет буквы **A–F** на числа из набора **1, 2, 3, 10, 20, 30**. Одинаковые буквы — одинаковые числа, разные буквы — разные числа. Нужно получить **самое короткое** число (а при равной длине — наименьшее).

Настрой станок для трёх строк:

1. `ABAABB`
2. `BABACCCA`
3. `DBACCADC`

**Ответ:**
1. `ABAABB` → **121122** (A → 1, B → 2);
2. `BABACCCA` → **12123332** (B → 1, A → 2, C → 3);
3. `DBACCADC` → **110233213** (B → 10, D → 1, A → 2, C → 3).

**Как рассуждать:**
- Сначала **длина кода**: каждая буква даёт столько цифр, сколько их в её числе. Значит, **самую частую** букву выгодно заменять **однозначным** числом, а **редкую** — двузначным (`10`, `20` или `30`).
- В третьей строке буква **B** встречается один раз, остальные — по два и больше, поэтому **B → 10** (код станет короче), а остальные буквы получают 1, 2, 3 **в порядке появления** (D → 1, A → 2, C → 3) — так число получается наименьшим.

**Критерий:** по 3 балла за каждый верный код.

**Интересный факт.** Это задача про **жадный алгоритм**: на каждом шаге выбираем то, что выгоднее прямо сейчас — сначала экономим цифры (частой букве короткое число), потом уменьшаем старшие разряды (редкой букве — двузначное). Тот же приём в кодировании и сжатии данных.
