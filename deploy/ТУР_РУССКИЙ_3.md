Олимпиадный тур для младших школьников. Основан на **пригласительном этапе ВсОШ 2025, русский язык, 3 класс** (файлы лежат локально в архиве), **формулировки переработаны в свои**, все ответы сверены с официальными критериями.

## История

В мастерской слов работает мастер. У него на столе — три ящика: **части слова**, **буквы** и **смысл**. Сегодня он просит помочь: разложить слова по составу, собрать новое слово из букв и понять, что значит маленькое слово «из».

## Ящик 1. Разбери слово по составу (3 балла)

Мастер высыпал три слова и три «схемы». Соедини слово с его составом:

| Слово | Схема |
|---|---|
| похолодело | корень, суффикс, окончание |
| хвастунишка | корень, суффикс, суффикс, окончание |
| холодище | приставка, корень, суффикс, суффикс, окончание |

**Ответ:** **холодище** — корень + суффикс + окончание (корень «холод», суффикс -ищ-, окончание -е); **хвастунишка** — корень + суффикс + суффикс + окончание (хваст- + -ун- + -ишк- + -а); **похолодело** — приставка + корень + суффикс + суффикс + окончание (по- + холод- + -е- + -л- + -о).

**Критерий:** по 1 баллу за каждую верную пару. Итого 3.

---

## Ящик 2. Собери анаграмму (3 балла)

**Анаграмма** — это новое слово, собранное из всех букв другого слова. Например: арка → кара.

Из всех букв слова **АКТЁР** собери слово-анаграмму — имя существительное, буквы не повторяются.

**Ответ:** **катер**, **тёрка** (терка) или **Артек** — любое из них.

**Критерий:** 3 балла за одно верное слово.

**Интересный факт.** Анаграммы любят поэты и учёные: из «Ломоносов» получается «Соломонов». А ещё слово-анаграмма всегда состоит из **тех же** букв — ни одной лишней, ни одной потерянной.

## Ящик 3. Что значит «из» (8 баллов)

Маленькое слово **из** умеет разное. Разложи словосочетания на **четыре группы** по значению:

- **множество, из которого выбирают**;
- **материал**;
- **место**;
- **причина**.

Словосочетания: *один из пассажиров · бусы из раковин · выход из вагона · отказ из вежливости · замок из песка · спросить из интереса · каждый из спортсменов · сокровища из сундука.*

**Ответ:**

| Группа | Словосочетания |
|---|---|
| множество, из которого выбирают | один из пассажиров; каждый из спортсменов |
| материал | бусы из раковин; замок из песка |
| место | выход из вагона; сокровища из сундука |
| причина | отказ из вежливости; спросить из интереса |

**Критерий:** по 1 баллу за каждую верную пару. Итого 8.

**Интересный факт.** Проверить группу просто: попробуй заменить «из» другим словом. «Отказ **из-за** вежливости» — причина; «бусы **из** раковин» — материал; «выход **из** вагона» — место; «один **из** пассажиров» — выбор из множества.
