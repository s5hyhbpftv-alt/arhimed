1. **Каждое** задание: снимок фигуры и сверка с вырезом из PDF глазами (зрением).
2. Гейт раскладки по всему уроку на **390 и 320 px** — ноль проблемных шагов.
3. Контраст, кегли по шкале, цели касания — аудит `qa_ui.py` по русскому направлению без нарушений.
4. Ошибок консоли нет.
5. Только после этого — одна выкладка с приложенным выводом всех проверок.

## Что запрещено в этой переделке

- Выкладывать частями: «сделал карту — выложил» больше не делаем.
