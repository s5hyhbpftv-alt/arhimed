# Промпт для генерации персонажей АРХИМЕД

Готовый промпт для генератора картинок, чтобы получить лист персонажа в том же
виде, что лист Архимеда владельца: пять выражений лица в верхнем ряду и фигура
в рост ниже. Из такого листа я нарезаю ассеты и подключаю их к урокам.

Подставь описание персонажа из таблицы ниже вместо `<ОПИСАНИЕ ПЕРСОНАЖА>`.

```
Лист персонажа для детского образовательного комикса. Один и тот же персонаж
в шести позах, нарисован вручную в едином стиле.

ВЕРХНИЙ РЯД — пять погрудных портретов в одинаковом масштабе, плечи видны,
лицо в три четверти, персонаж смотрит на зрителя:
1) спокойная добрая улыбка,
2) удивление: брови вверх, глаза широко раскрыты, рот приоткрыт,
3) задумчивость: взгляд в сторону и вверх, брови чуть сдвинуты, рука у подбородка,
```

## English prompt (recommended — image models follow it more precisely)

Fill `<CHARACTER>` with a line from the table below. This single block gives the
same sheet as the owner's Archimedes sheet: five bust variations on top, one
full-body pose below.

### Master prompt

```
Character model sheet for a children's educational comic, one single character
in six poses, hand-drawn 2D illustration, consistent design across all poses.

LAYOUT
- Top row: five bust portraits of the same character, identical scale, shoulders
  fully visible, three-quarter view, facing the viewer, evenly spaced with clear
  background gaps between them, none touching.
- Bottom: the same character in one full-body standing pose, facing the viewer,
  complete figure — head, arms, hands, legs and both feet fully visible, nothing
  cropped, generous margin below the feet.

EXPRESSIONS (left to right on the top row)
1. calm friendly smile, relaxed brows
2. surprised: eyebrows raised, eyes wide open, mouth slightly open
3. thinking: looking up and to the side, brows slightly drawn, hand resting
   against the chin
4. laughing: eyes squeezed shut in happy arcs, mouth wide open, joyful
5. sad: inner ends of the eyebrows raised, mouth corners turned down

STYLE
Hand-drawn children's book illustration; soft painterly shading with gentle
gradients; thin dark clean outline; warm saturated palette; kind, appealing
character design for ages 6-8; flat cream background only. Same drawing style,
same line weight and same shading technique in every pose.

BACKGROUND
Flat uniform warm cream #F6EFDC, no gradient, no texture, no cast shadow, no
floor, no props, no scenery.

HARD REQUIREMENTS
- No text, no captions, no letters, no numbers, no logo, no watermark, no
  signature anywhere in the image.
- Identical character in all six poses: same clothing, same colours, same hair
  or fur, same accessories, same proportions.
- Clean crisp edges; smooth solid fills; no noise, no jpeg artefacts.
- Full figure inside the frame with even margins.

<CHARACTER>

Aspect ratio 3:2.
```

### Negative prompt

For Stable Diffusion / Flux style tools that take a separate negative field:

```
text, caption, letters, numbers, watermark, signature, logo, labels, speech
bubbles, blurry, low resolution, jpeg artefacts, noise, extra limbs, extra
fingers, deformed hands, cropped feet, cropped head, cut off, duplicate
character, inconsistent design, busy background, gradient background, cast
shadow, floor, furniture, scenery, photorealism, 3D render, harsh cartoon
outline, scary expression
```

### Style-reference clause

Attach the owner's Archimedes sheet (`MVP/img/archimedes_sheet.jpg`) as a style
reference and prepend this line:

```
Match the attached reference sheet exactly in drawing style: line weight,
soft painterly shading, colour temperature, and the flat cream background.
Keep the same layout: five bust variations in one row, one full-body pose below.
```

### Tool notes

- **Midjourney**: paste the master prompt, add `--ar 3:2 --style raw --no text, watermark, letters, numbers, speech bubbles`.
- **DALL·E / GPT-image**: plain sentences work best — keep the LAYOUT, EXPRESSIONS and STYLE paragraphs, drop the code-style structure.
- **Flux / Stable Diffusion**: use the master prompt with the negative prompt above; CFG 3.5-5, 30-40 steps, then re-run any pose that came out inconsistent.
- If a sheet comes back with inconsistent poses, generate it again asking for **fewer poses** (three instead of six) and combine two sheets — consistency holds better with fewer variations per image.

## Как я потом нарежу (что нужно от листа)

- **Ровный однотонный фон** без градиента и тени: по нему я отделяю персонажа
  от фона и делаю прозрачную подложку.
- **Головы не касаются друг друга и краёв**: между ними должен быть просвет
  фона, иначе границы придётся угадывать.
- **Плечи у портретов видны полностью** — так же, как на листе Архимеда.
- **Фигура в рост целиком**, ступни не обрезаны краем листа.
- **Без надписей** на картинке: подписи я ставлю сам в приложении.
- **Ровные поля** по краям кадра.

## Чек-лист приёмки листа

1. Шесть поз одного и того же персонажа — одежда, цвета и причёска совпадают.
2. Пять выражений читаются: улыбка, удивление, задумчивость, смех, огорчение.
3. В рост — голова, руки, ноги и ступни целиком.
4. Текста на картинке нет.
5. Фон однотонный, между фигурами просветы.
6. Пропорции детские и добрые, без карикатуры и без взрослой «реалистичности».

## Эмоции, которые понимает движок уроков

Кадр урока задаёт эмоцию служебным словом, и лист должен закрывать все пять:

| Слово в данных | Что значит | Из листа берётся |
|---|---|---|
| `smile` | спокойный, добрый | портрет 1 |

| `think` | задумался | портрет 3 |
| `laugh` | смеётся | портрет 4 |
| `sad` | огорчён | портрет 5 |
| — | говорит один, без собеседника | фигура в рост |
