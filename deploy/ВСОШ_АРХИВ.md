# Архив заданий ВсОШ по нашим предметам (классы 1–9)

Что собрано, откуда и как добрать ещё. Файлы лежат **локально** в `deploy/всош/` — материалы авторские, в публичный репозиторий не идут (правило в `.gitignore`). В репозитории остаётся этот разбор.

## Откуда взято

На официальном сайте ВсОШ (`vos.olimpiada.ru`) раздел «Задания» работает на скрытом API. Нашёл два адреса:

- **`https://vos.olimpiada.ru/api/getSubjectsList`** — список предметов (id, название, код);
- **`https://vos.olimpiada.ru/api/getTasks`** — весь архив заданий одним JSON: **4,9 МБ, 1703 записи, 14 163 ссылки на PDF**.

Ссылки внутри имеют вид `…/Arhive_tasks/<сезон>/<этап>/<предмет>/tasks-<предмет>-<классы>-<этап>-msk-<сезон>.pdf`, рядом — `sol-…` с решениями. То есть в архиве лежат **и задания, и решения, по классам и этапам**.

Этапы в архиве: `prigl` — пригласительный, `school` — школьный, `mun` — муниципальный, `reg` — региональный, `final` — заключительный.

## Что в архиве по нашим предметам всего (не только скачанное)

По всем сезонам (2012/13–2026/27), только наши предметы и классы 1–9 — **782 файла**: математика 317, химия 178, физика 176, русский 111, информатика — код `iikt` (в скачанном 82). При желании можно добрать и более старые сезоны тем же скриптом.

## Как добрать остальное

Скрипты лежат во временной папке сессии и повторяются так:

1. `curl -s https://vos.olimpiada.ru/api/getTasks -o /tmp/tsk.json` — забрать архив (4,9 МБ);
2. разобрать ссылки, отфильтровать по сезону, предмету (коды: `math`, `russ`, `phys`, `chem`, `iikt`) и классам;
3. скачать по адресу `https://vos.olimpiada.ru<ссылка>` в `deploy/всош/<сезон>/<этап>/<предмет>/`.

## Что это даёт проекту

1. **Готовый банк олимпиадных задач по классам** — с решениями. Это основа для олимпиадной линии «Путь Мишутки»: сейчас у нас задачи берутся точечно (олимпиада школы № 1517, отдельные примеры), а здесь — системный архив по каждому классу и каждому этапу.
2. **Сверка с программой ЦПМ.** У ЦПМ для 5 класса методы: индукция, Дирихле, оценки, раскраски, от противного, инварианты. Теперь под каждый метод можно подобрать **официальные задачи ВсОШ** соответствующего класса и этапа, а не выдумывать.
3. **Младшая школа.** Задания с 1 класса закрывают пробел: для 1–4 классов официальных диагностик (МЦКО, ВПР) нет, а олимпиадные задачи есть.
4. **Формат «тур».** Этапы архива — это готовые туры: можно собирать проверочные работы олимпиадной линии как тур из 4–6 задач соответствующего этапа.

## Что дальше (по приоритету)

1. **Разложить математические задачи ВсОШ по методам ЦПМ** (индукция, Дирихле, оценки, раскраски, инварианты, от противного) — и по классам: получится план олимпиадных уроков, обеспеченный задачами с решениями.
2. **Сверить покрытие по классам**: сколько задач есть на каждый класс и каких тем не хватает.
3. **Отобрать по 3–5 задач на урок** для «Пути Мишутки», с решениями — по образцу того, как сделаны уроки 623 (логика без перебора) и 624 (среднее и прикидка).
