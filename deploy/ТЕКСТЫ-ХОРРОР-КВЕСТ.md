# Тексты и шрифты для хоррор-квеста «Мишутка и ночная школа»

Всё готово к копированию. Тексты сгруппированы **по роли страницы**, а не по номерам: в твоём
шаблоне число страниц своё, поэтому подставляй по смыслу («страница комнаты», «страница
разбора», «сейф», «финал»).

Математика — 6 класс: дроби, проценты, делимость, координаты, пропорции.

---

## 1. Шрифты

### Сразу важное

**Проверь, есть ли у шрифта кириллица.** У большинства «страшных» декоративных шрифтов её нет:
`Creepster`, `Nosifer`, `Eater`, `Special Elite`, `Rubik Wet Paint` — **русский текст в них
свалится в системный шрифт**, и весь вид поедет. Ниже только шрифты с кириллицей.

### Пара для квеста (рекомендую)

| Роль | Шрифт | Почему |
|---|---|---|
| **Заголовки, названия комнат** | **Ruslan Display** | Кириллица, тяжёлый «древний» шрифт — сам по себе создаёт мрачную атмосферу. Идеален для названия квеста и названий кабинетов |
| **Основной текст задач** | **PT Serif** | Кириллица родная, отлично читается на телефоне в 16–20 px. Не отвлекает от атмосферы |
| **Записки, мел на доске, подсказки** | **Neucha** | Кириллица, «рукописный» — как будто писал ученик |
| **Код, цифры сейфа** | **PT Mono** | Кириллица, моноширинный — цифры в клетках сейфа стоят ровно |

### Запасные варианты (тоже с кириллицей)

- Заголовки: **Yeseva One** (декоративный, торжественный), **Playfair Display**, **Cormorant SC**.
- Текст: **PT Sans**, **Noto Serif**, **Rubik**.
- Записки: **Caveat**, **Bad Script**.
- Цифры: **Oswald**, **JetBrains Mono**.

### Как поставить в Genially

1. В редакторе: `Insert → Text` → в панели шрифта нажать на название → внизу списка **Add font**
   (`+ Добавить шрифт`).
2. В поиске набрать название (например `Ruslan Display`) → **Add**.
3. Шрифт появится в списке; выбрать его для блока.
4. Повторить для каждого из четырёх шрифтов.

### Размеры (по стандарту проекта, ниже нельзя)

| Что | Кегль |
|---|---|
| Название квеста на титуле | 48 |
| Названия страниц и комнат | 32 |
| Основной текст задачи | 20 |
| Подписи, счёт, подсказки | 14 (минимум, не меньше) |
| Цифры в клетках сейфа | 32, моноширинный |

**Цвет:** заголовки `#d9a441` (золото), текст `#e8e0cc`, подписи `#9fb0a0`, фон `#0b1712`.

## 5. Комната 1 · дроби

**Заголовок:**

```
КАБИНЕТ 1 · ДРОБИ
```

**Атмосфера (Neucha, 16):**

```
Дверь скрипнула и закрылась за спиной. На доске мелом написано задание.
```

**Задача (PT Serif, 20):**

```
На доске два куска мела разной длины: 1/4 и 1/6.
Сколько всего мела, если сложить куски?
```

**Варианты (кнопки):**

```
5/12
```
```
2/10
```
```
5/10
```

**Разбор ошибки (страница «неверно»):**

```
Почти! Чтобы сложить дроби, нужен общий знаменатель.
Общий знаменатель для 4 и 6 — это 12.
1/4 = 3/12, а 1/6 = 2/12.
Складываем: 3/12 + 2/12 = 5/12.
Вернись к доске и попробуй снова.
```

**Кнопка разбора:**

```
Вернуться к доске
```

**Страница «друг найден»:**

```
ЗА ДОСКОЙ КТО-ТО ЕСТЬ
```
```
Ты отодвинул доску — там сидел друг. Он дрожал, но улыбнулся.
На стене мелом проступила цифра: 4
```

**Кнопка:**

```
Дальше
```

## 6. Комната 2 · проценты

**Заголовок:**

```
КАБИНЕТ 2 · ПРОЦЕНТЫ
```

**Атмосфера:**

```
В шкафу мигает лампочка. На полях тетради — расчёт, но одно число стёрто.
```

**Задача:**

```
15% числа равны 45. Найди это число.
```

**Варианты:**

```
300
```
```
675
```
```
60
```

**Разбор ошибки:**

```
Проценты — это сотые доли. Если 15% — это 45,
то 1% — это 45 : 15 = 3, а всё число — 3 · 100 = 300.
Вернись и посчитай ещё раз.
```

**Страница «друг найден»:**

```
В ШКАФУ КТО-ТО ДЫШИТ
```
```
Дверца открылась, и оттуда выпал друг — он прятался от темноты.
На тетрадном листе проступила цифра: 7
```

## 7. Комната 3 · делимость

**Заголовок:**

```
КАБИНЕТ 3 · ДЕЛИМОСТЬ
```

**Атмосфера:**

```
На столе рассыпаны счётные палочки. Их надо разложить по коробкам поровну.
```

**Задача:**

```
В коробке 48 палочек, в другой 36.
На какое наибольшее число кучек можно разложить их поровну
так, чтобы в каждой кучке были палочки из обеих коробок?
Найди НОД(48; 36).
```

**Варианты:**

```
12
```
```
6
```
```
144
```

**Разбор ошибки:**

```
НОД — наибольший общий делитель.
48 = 2·2·2·2·3, 36 = 2·2·3·3.
Общие множители: 2 · 2 · 3 = 12.
144 — это НОК, наименьшее общее кратное, а не НОД.
```

**Страница «друг найден»:**

```
ПОД СТОЛОМ КТО-ТО СПРЯТАЛСЯ
```
```
Друг сидел среди палочек и раскладывал их по кучкам — ему тоже было страшно.
На коробке проступила цифра: 2
```

## 8. Комната 4 · координаты

**Заголовок:**

```
КАБИНЕТ 4 · КООРДИНАТЫ
```

**Атмосфера:**

```
На стене висит сетка, как карта звёздного неба. Одна точка обведена.
```

**Задача:**

```
Точка A имеет координаты (−3; 4).
В какой четверти координатной плоскости она находится?
```

**Варианты:**

```
II
```
```
III
```
```
IV
```

**Разбор ошибки:**

```
Отсчёт четвертей идёт против часовой стрелки от правого верхнего угла.
У точки x = −3 (влево от оси), y = 4 (вверх от оси).
Значит, она во второй четверти: II.
```

**Страница «друг найден»:**

```
ЗА СЕТКОЙ КТО-ТО СТОИТ
```
```
Друг стоял и смотрел на карту звёзд — он ждал, что его найдут.
В углу сетки проступила цифра: 9
```

## 9. Сейф

**Заголовок:**

```
СЕЙФ
```

**Текст:**

```
Ты нашёл всех друзей. На стене — сейф с четырьмя клетками.
В каждой комнате была цифра. Собери их по порядку: 1 → 2 → 3 → 4.
```

**Подсказка (Neucha):**

```
Код — четыре цифры. Каждая осталась в своей комнате.
```

**Неверный код:**

```
Сейф не поддался. Где-то щёлкнул замок, но дверца осталась закрыта.
Проверь цифры: их было четыре, и каждая — из своей комнаты.
```

**Верный код (4 7 2 9):**

```
ЩЁЛК. Сейф открылся. Внутри лежит ключ от главной двери.
```

## 10. Комната 5 · пропорции (за главной дверью)

**Заголовок:**

```
ПОСЛЕДНЯЯ ДВЕРЬ · ПРОПОРЦИИ
```

**Атмосфера:**

```
Главная дверь открылась, и свет фонаря упал на доску. Последняя задача.
```

**Задача:**

```
Реши пропорцию: x / 8 = 9 / 12.
```

**Варианты:**

```
6
```
```
12
```
```
4
```

**Разбор ошибки:**

```
В пропорции произведение крайних равно произведению средних:
x · 12 = 8 · 9, то есть 12x = 72, значит x = 6.
```

## 13. Что проверить после вставки текстов

- [ ] Все четыре шрифта добавлены и **кириллица отображается** (проверить на заголовке и записке).
- [ ] Кегли: заголовок 32, текст 20, подписи не меньше 14. Ничего мельче.
- [ ] Текст не налезает на картинки: под текст положена затемняющая подложка `#0b1712`, 45 %.
- [ ] Длина строки не больше 75 знаков — иначе блок текста узкий и высокий, на телефоне читать тяжело.
- [ ] Счёт «Друзей найдено» на каждой копии холла совпадает с числом открытых дверей.
- [ ] Цифры кода (4, 7, 2, 9) стоят в комнатах 1–4 по порядку, и в сейфе сказано «1 → 2 → 3 → 4».
- [ ] Ответы сверены: 5/12 · 300 · 12 · II · 6.
