## Дело 1. Краска для задника (7 баллов)

**Условие.** В чану осталось **70 литров** готовой смеси: красной краски в ней **20 %**, зелёной — **35 %**, синей — **45 %**. Для задника нужна другая смесь: **25 %** красной, **40 %** зелёной и **35 %** синей. Синяя краска в мастерской закончилась, доливать её нельзя.

**Сколько литров красной и сколько литров зелёной краски нужно влить в чан?**

**Ответ: красной — 8,5 л, зелёной — 11,5 л.**

**Ход решения.** Синяя краска не добавляется — значит, её объём в чану не изменится. Сейчас её `70 · 0,45 = 31,5 л`. В новой смеси та же синяя составляет 35 %, откуда сразу находится новый общий объём:
`x = 31,5 / 0,35 = 90 л`.
Значит, красной в новой смеси должно стать `90 · 0,25 = 22,5 л`, а сейчас её `70 · 0,20 = 14 л`. Долить нужно `22,5 − 14 = 8,5 л`.
Зелёной должно стать `90 · 0,40 = 36 л`, а сейчас `70 · 0,35 = 24,5 л`. Долить нужно `36 − 24,5 = 11,5 л`.
Проверка по балансу: `22,5 + 36 + 31,5 = 90 л`, доли равны `22,5/90 = 25 %`, `36/90 = 40 %`, `31,5/90 = 35 %` — ровно то, что требовалось.

**Критерий (по официальным):** точное совпадение ответа — 7 баллов; если верно только одно из двух чисел — 3 балла.

**Интересный факт.** Неизменный компонент — самый удобный «якорь» в задачах на смеси: доля синей упала с 45 % до 35 %, значит, весь объём вырос ровно в `45/35 = 9/7` раза, то есть с 70 до 90 литров. Один такой пересчёт «от того, что не меняется», заменяет систему уравнений с двумя неизвестными.

## Дело 2. Шесть номерков и три ящика (7 баллов)

**Условие.** Для лотереи приготовили шесть номерков с числами **3, 7, 10, 16, 23 и 31**. Их нужно разложить по трём ящикам по два номерка так, чтобы выполнялись все три правила:

- в первом ящике лежат только простые числа;
- во втором ящике сумма чисел делится на 3;
- сумма чисел в третьем ящике больше половины общей суммы всех шести номерков.

**Какие числа попадут в каждый ящик?**

**Ответ: первый ящик — 3 и 7, второй — 10 и 23, третий — 16 и 31.**

**Ход решения.** Считаем общую сумму: `3 + 7 + 10 + 16 + 23 + 31 = 90`. Половина — 45, значит, третья пара в сумме больше 45. Из шести чисел такую сумму дают только две пары: `16 + 31 = 47` и `23 + 31 = 54`. В обеих есть 31 — он обязательно в третьем ящике.

Дальше смотрим на остатки при делении на 3: у 7, 10, 16 и 31 остаток 1, у 3 остаток 0, у 23 остаток 2. Сумма пары делится на 3, только если остатки пары дают 0 или 3. Единственный номерок с остатком 2 — это 23, поэтому во второй ящик попадает 23 в паре с числом, у которого остаток 1.

Перебираем два варианта для третьего ящика.
Если третий ящик — 16 и 31, то остаются 3, 7, 10, 23. Первый ящик — пара простых: 3 и 7 (тогда во втором 10 и 23, их сумма 33 делится на 3 — подходит), 3 и 23 (тогда во втором 7 и 10, сумма 17 — не делится), 7 и 23 (тогда во втором 3 и 10, сумма 13 — не делится). Годится только первый расклад.
Если третий ящик — 23 и 31, то остаются 3, 7, 10, 16. Пара простых тут единственная — 3 и 7, а во втором ящике остаются 10 и 16, их сумма 26 на 3 не делится. Вариант отпадает.

Остаётся один расклад: **первый ящик — 3 и 7, второй — 10 и 23, третий — 16 и 31**. Проверка: 3 и 7 простые; `10 + 23 = 33` делится на 3; `16 + 31 = 47 > 45`.

**Критерий (по официальным):** точное совпадение ответа — 7 баллов.

**Интересный факт.** Простые числа, кроме двойки, все нечётные, поэтому в задачах на разбиение полезно смотреть не на сами числа, а на их остатки: здесь решающими оказались остатки при делении на 3, а не величина номерков. А ещё сумма всех номерков — 90, и это сразу выдало 31 как обязательного участника третьего ящика: самое большое число почти всегда уезжает в самую «тяжёлую» группу.

## Дело 3. Рецепт грунтовки (7 баллов)

**Условие.** В старом рецепте грунтовки пропорция записана дробью: берут `a` частей одного состава и `b` частей другого, а проверочное число рецепта равно `(7a + 9b) / (a + 3b)`. Мастер помнит только, что `a` и `b` — **натуральные** числа и что проверочное число тоже получилось **натуральным**.

**Какие значения может принимать отношение a/b? Укажи все варианты.**

**Ответ: 1; 3; 9.**

**Ход решения.** Выделим из дроби целую часть:
`(7a + 9b) / (a + 3b) = (3(a + 3b) + 4a) / (a + 3b) = 3 + 4a/(a + 3b)`.
Второе слагаемое положительно (числа натуральные, значит `a > 0`) и меньше 4, потому что знаменатель `a + 3b` больше числителя `4a` при `a + 3b > 4a`, то есть при `3b > 3a`. Аккуратнее так: `4a/(a + 3b) < 4` равносильно `4a < 4a + 12b`, а это верно при любом натуральном `b`. Итак, вся дробь строго больше 3 и строго меньше 7. Натуральных чисел там ровно три: 4, 5 и 6. Разбираем каждое.

1. Дробь равна 4: `7a + 9b = 4a + 12b`, откуда `3a = 3b`, то есть `a/b = 1`. Подходит, например, `a = b = 1`: `(7 + 9)/(1 + 3) = 16/4 = 4`.
2. Дробь равна 5: `7a + 9b = 5a + 15b`, откуда `2a = 6b`, то есть `a/b = 3`. Подходит `a = 3, b = 1`: `(21 + 9)/(3 + 3) = 30/6 = 5`.
3. Дробь равна 6: `7a + 9b = 6a + 18b`, откуда `a = 9b`, то есть `a/b = 9`. Подходит `a = 9, b = 1`: `(63 + 9)/(9 + 3) = 72/12 = 6`.

Все три отношения действительно достигаются, других значений у дроби быть не может.

**Критерий (по официальным):** точное совпадение ответа — 7 баллов (нужны все три значения).

**Интересный факт.** Такая дробь всегда «зажата» между двумя предельными числами: если в числителе и знаменателе оставить только слагаемые с `b`, получится 3, а если только с `a` — получится 7. Оценка выражения с двух сторон — самый быстрый способ убить бесконечный перебор: вместо тысяч пар `a` и `b` остаются три варианта.

## Дело 4. Отбор команд на карнавал (7 баллов)

**Условие.** На командный турнир карнавала подали заявки **80 команд**. Отбор идёт по жёстким правилам. У каждой команды есть счёт побед и поражений, изначально 0–0. В каждом матче играют **две команды с одинаковым текущим счётом**, одна побеждает, другая проигрывает; ничьих не бывает. Как только команда набирает **3 поражения**, она выбывает. Как только команда набирает **3 победы**, она проходит в главную часть турнира и тоже больше не играет. Отбор заканчивается, когда судьба каждой команды определена.

**(а) Сколько команд пройдёт в главную часть? (б) Сколько всего матчей будет сыграно?**

**Ответ: (а) 40 команд; (б) 165 матчей.**

**Ход решения.** В матче встречаются команды с одинаковым счётом, значит, у них и число сыгранных матчей одинаковое. Поэтому отбор удобно считать раундами: в каждом раунде все команды, ещё не определившиеся, разбиваются на пары и играют.

- **Раунд 1:** 80 команд, 40 матчей. Получаем 40 команд со счётом 1–0 и 40 команд со счётом 0–1.
- **Раунд 2:** ещё 40 матчей. Из первых 40: 20 команд 2–0 и 20 команд 1–1. Из вторых 40: 20 команд 1–1 и 20 команд 0–2. Итого 20 команд 2–0, 40 команд 1–1, 20 команд 0–2.
- **Раунд 3:** снова 40 матчей (20 в группе 1–1, по 10 в группах 2–0 и 0–2). Получаем 10 команд 3–0 — они прошли отбор, 30 команд 2–1, 30 команд 1–2 и 10 команд 0–3 — они выбыли.
- **Раунд 4:** играют только 30 команд 2–1 и 30 команд 1–2, это 15 + 15 = 30 матчей. Отсюда 15 команд уходят в главную часть со счётом 3–1, 15 команд выбывают со счётом 1–3, а ещё 30 команд оказываются со счётом 2–2.
- **Раунд 5:** 30 команд 2–2 играют 15 матчей; 15 победителей проходят со счётом 3–2, 15 проигравших выбывают со счётом 2–3.

Складываем прошедших: `10 + 15 + 15 = 40` команд. Складываем матчи: `40 + 40 + 40 + 30 + 15 = 165`.

Проверка вторым способом: посчитаем суммарное число поражений у всех команд. Выбывшие: 10 команд по 3 поражения, 15 команд по 3 и ещё 15 по 3 — итого 120. Прошедшие: 10 команд с 0 поражений, 15 с одним и 15 с двумя — итого `0 + 15 + 30 = 45`. Всего поражений `120 + 45 = 165`, а поражений в турнире ровно столько же, сколько матчей. Сходится.

**Критерий (по официальным):** точное совпадение ответа в пункте (а) — 1 балл; точное совпадение ответа в пункте (б) — 6 баллов.

**Интересный факт.** Правила отбора симметричны относительно побед и поражений: если в каждом матче поменять победителя с проигравшим, отбор устроится точно так же, только команды с тремя победами и команды с тремя поражениями поменяются ролями. Поэтому прошедших всегда ровно столько же, сколько выбывших, — ровно половина заявок.

## Дело 5. Окна-медальоны на створке (7 баллов)

**Условие.** Створка для декорации — прямоугольный треугольник `ABC` с прямым углом при вершине `C`. В ней прорезают два круглых окна. Первое — с центром в вершине `A`, проходящее через `C`; его дуга пересекает гипотенузу `AB` в точке `E`. Второе — с центром в вершине `B`, тоже проходящее через `C`; его дуга пересекает гипотенузу в точке `D`. Известно, что `AD = 16`, а `BE = 50`.

**Найди длину отрезка DE.**

**Ответ: DE = 40.**

**Ход решения.** Обозначим `DE = x`. Сначала разберёмся с порядком точек на гипотенузе. Оба катета вместе длиннее гипотенузы, поэтому `AD + EB < AB`: точки `D` и `E` лежат внутри гипотенузы, причём `D` ближе к `A`, а `E` — к `B`. Значит, порядок такой: `A`, `D`, `E`, `B`.

Теперь читаем радиусы. Окружность с центром `A` проходит через `C`, поэтому `AC = AE = AD + DE = 16 + x`. Окружность с центром `B` проходит через `C`, поэтому `BC = BD = BE + ED = 50 + x`. Вся гипотенуза: `AB = AD + DE + EB = 16 + x + 50 = 66 + x`.

Осталась теорема Пифагора для треугольника `ABC`:
`(16 + x)² + (50 + x)² = (66 + x)²`.
Раскрываем скобки:
`256 + 32x + x² + 2500 + 100x + x² = 4356 + 132x + x²`.
Слева два `x²`, справа один, и слагаемые `132x` в обеих частях одинаковы — они сокращаются. Остаётся
`x² = 4356 − 256 − 2500 = 1600`, то есть `x = 40`.

Проверка: катеты `56` и `90`, гипотенуза `106`; `56² + 90² = 3136 + 8100 = 11236 = 106²`. Всё сходится.

**Критерий (по официальным):** точное совпадение ответа — 7 баллов.

**Интересный факт.** Числа в задаче подобраны так, что получился удвоенный пифагоров треугольник 28–45–53: катеты 56 и 90, гипотенуза 106. А общая формула ответа совсем короткая: `DE = √(2 · AD · BE)`, здесь `√(2 · 16 · 50) = √1600 = 40`.
