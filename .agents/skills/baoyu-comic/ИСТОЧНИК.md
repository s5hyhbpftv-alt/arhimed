# Откуда этот скил

Скачан как есть из [JimLiu/baoyu-skills](https://github.com/JimLiu/baoyu-skills) → `skills/baoyu-comic`
(автор 宝玉, лицензия MIT). Локальная копия нужна как справочник по методу: стили рисунка,
раскладки панелей, шаблон раскадровки, шаблон героя, таблица «абстрактное → образ».

**Он не запускается в этом окружении и не должен:** скил с первого шага требует растрового
генератора картинок (`imagegen`, `GenerateImage`, `image_generate` или `codex exec`), а в проекте
АРХИМЕД всё нарисовано кодом — SVG в `MVP/js/comic.js`. Сам скил прямо запрещает подменять
растровую генерацию на SVG и canvas.

Поэтому:
- **брать отсюда метод** — можно и нужно (ракурсы, свет, композиция панелей, образы абстракций);
- **выполнять его шаги** — нельзя, пока в окружении нет растрового бэкенда;
- **наша рабочая версия метода под покадровый SVG** — скил `arhimed-comic`
  (см. `.agents/skills/arhimed-comic/SKILL.md`), он и есть руководство для этого проекта.

Если появится ключ сервиса генерации картинок или локальная модель — исходный скил можно
использовать для отдельной задачи (например, обложки витрины), но не для героев и сцен
приложения: растровая картинка в ряду нарисованных кодом выглядит наклейкой.
