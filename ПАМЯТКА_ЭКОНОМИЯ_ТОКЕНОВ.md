# Режим экономии токенов — памятка сессии

Дата: 05.09.2026. Решение пользователя: сократить расход токенов.

## Правила работы (соблюдать в этой и следующих сессиях)
1. **Отчёты короткие**: итог + ссылки + что дальше. Без пересказа данных, которые уже лежат в файлах.
2. **Один источник правды — файлы**: `план-1-9/` (планы, аудит), `MVP/data/lessons.js`, `MVP/js/*.js`. Не дублировать содержимое в чат.
3. **Не поднимать фоновых субагентов без необходимости**: исследования хранить в файлах (`*.md`, `*.json`), а не в переписке. Финальные отчёты субагентов присылать одним сообщением, не переспрашивать.
4. **Читать файлы точечно** (grep + read с limit), не открывать целиком большие JS.
5. **Проверки — выборочно**: скриншоты только изменённого; vision на 2–3 кадра, не на все; геометрию проверять DOM-замерами вместо массовых скриншотов.
6. **Переиспользовать артефакты**: генераторы презентаций и скрипты проверки держать в workspace (не в /tmp), пересобирать инкрементально.
7. **Меньше уточняющих вопросов**: действовать по контексту, задавать вопрос только при реальной развилке.
8. **Не запускать повторно завершённые субагенты и джобы**; в конце сессии чистить свои /tmp-файлы (скриншоты, логи).
