# Развёртывание на VPS (Джино и любой другой Linux-VPS)

Чтобы **голосовой агент работал с телефона**, приложение должно жить на сервере,
где постоянно запущен Python-процесс. GitHub Pages для этого не подходит (статический хостинг).

## Что нужно

1. **VPS** на Джино (Linux, Ubuntu 22.04/24.04 или Debian 12) — минимум 1 vCPU / 1 ГБ RAM.
   Джино.Хостинг (shared) НЕ подходит: там нельзя держать постоянный WebSocket-процесс.
2. **Домен**, привязанный к VPS: в панели DNS укажите A-запись `домен → IP сервера`.
3. **API-ключ Яндекса** (уже есть в `ключ_яндекса.txt` на рабочем Mac).

## Установка (одна команда от root)

```bash
apt-get update && apt-get install -y curl
bash <(curl -sL https://raw.githubusercontent.com/s5hyhbpftv-alt/arhimed/main/deploy_vps.sh) \
  ваш-домен.ru \
  ВАШ_КЛЮЧ_ЯНДЕКСА
```

Скрипт делает всё сам:
1. ставит Python 3, nginx, certbot;
2. клонирует проект (код — из GitHub, ключ — только на сервере);
3. кладёт ключ в `ключ_яндекса.txt` (chmod 600);
4. ставит `aiohttp` в venv;
5. создаёт systemd-сервис `arhimed` (порт 8130) — работает 24/7 и сам перезапускается;
6. настраивает nginx-прокси с поддержкой WebSocket;
7. выпускает бесплатный HTTPS-сертификат Let's Encrypt.

## Проверка

| Что | Адрес |
|---|---|
| Приложение | `https://ваш-домен.ru/MVP/` |
| Голосовой агент (WS) | `wss://ваш-домен.ru/agent` |

Клиент определяет адрес агента автоматически: если страница открыта по HTTPS —
подключается к `wss://<тот же домен>/agent`, если локально — к `ws://хост:8125/agent`.

## Полезные команды на сервере

```bash
systemctl status arhimed      # состояние шлюза
journalctl -u arhimed -f      # логи в реальном времени
systemctl restart arhimed     # перезапуск после обновления кода
```

## Обновление кода на сервере после изменений в репозитории

```bash
cd /opt/arhimed && git pull && systemctl restart arhimed
```

## Безопасность

- Ключ Яндекса **никогда не попадает в GitHub** — он лежит только в
  `/opt/arhimed/ключ_яндекса.txt` на сервере (и локально на вашем Mac).
- Если ключ утёк — отзовите его в кабинете Яндекс.Облака и выпустите новый.
