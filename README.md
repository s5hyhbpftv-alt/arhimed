# Проект «АРХИМЕД» — игровая вселенная олимпиадной математики и физики

> Интерактивная платформа для школьников 10–17 лет: сюжетные острова, ИИ-наставник, виртуальная лаборатория, дуэли и родительский кабинет. Модуль «Химия» — в расширении.

## 🌐 Живое демо (GitHub Pages)

- **Витрина проекта**: https://s5hyhbpftv-alt.github.io/arhimed/
- **MVP-приложение**: https://s5hyhbpftv-alt.github.io/arhimed/MVP/ — работает прямо в браузере (5 разделов: «Начальная школа» (1–4 кл) + 4 острова, 87 задач (71 основная + 80 для 1–4 классов), 62 урока с разбивкой по предметам, легенда). Голосовая озвучка и живой агент требуют локальных серверов `tts_server.py` (8124) и `агент_сервер.py` (8125) с ключом Яндекса.
- Репозиторий: https://github.com/s5hyhbpftv-alt/arhimed

## 🎯 Ключевая идея (в двух словах)

**«АРХИМЕД»** = *Duolingo × AoPS × PhET × сюжетный сериал × ИИ-тьютор + родительский дашборд.*

- **Детям:** приключение вместо «ещё одного курса» — задачи вшиты в историю, ИИ-Архимед ведёт наводящими вопросами, дуэли и турниры дают драйв.
- **Родителям:** видимый прогресс, прогноз олимпиадных результатов, безопасная среда, честные деньги.
- **Ниша (доказана исследованием):** русскоязычных адаптивных тренажёров олимпиадных приёмов нет; виртуальная лаборатория экспериментального тура не существует нигде; геймификация олимпиадного уровня отсутствует у всех РФ-игроков.
