## 2. Темы задач финала (единый комплект, оба тура) — по официальным разборам

### Тур 1 (24 марта 2026), задачи 1–4
1. **«Распределённые системы»** — перестановка-«резервы» (граф i→p_i = набор ориентированных циклов); отключение ≤k серверов «склеивает» серверы по циклу. Ответ = макс. сумма a_i по циклическому подотрезку длины ≤ k+1; решение — **скользящее окно/суммы по циклам**, O(n). (Разбор: «циклы перестановки», «скользящее окно».)
2. **«Расследование в Темерии»** — обход взвешенного **дерева** из корня с возвратом + ≤k «кристаллов-телепортов» (телепорт эффективен по вертикальным путям); задача сводится к выбору k максимальных **вершинно-непересекающихся путей** в дереве. Решения: **ДП-«рюкзак на дереве»** (dp[v][s]) и жадный алгоритм добавления путей (доказательство — сведение к MCMF/min-cost max-flow), реализация со **структурами данных (дерево отрезков + эйлеров обход)**, n≤500 000.
3. **«Скобки и деревья»** — **интерактивная задача с двойным запуском**: закодировать последовательность корневых (неупорядоченных) деревьев, данных как ПСП, в одно дерево-ПСП и восстановить её во втором запуске. Тематика: **строки/правильные скобочные последовательности, кодирование деревьев, хеширование поддеревьев** (полное решение — случайный «маркер»-поддерево с детерминированной инициализацией генератора, битовые маски деревьев малого размера, префиксные балансы).
4. **«Спортивная тренировка»** — «допустимые пары» в ряду (номера = рост) и максимальное число передач мяча; переформулируется в **строки над алфавитом {L,R,M} + конечный автомат/ДП**; онлайн-добавление участников слева/справа. Решения: **два монотонных дека + дерево отрезков** (max-plus матрицы 3×3; автомат из 20 состояний), либо блоки + стеки рекордов + std::set/дерево Фенвика; O((n+q) log(n+q)).

### Тур 2 (26 марта 2026), задачи 5–8
5. **«Обобщённые шахматы»** — доска n×n, для каждого подпрямоугольника [1..r]×[1..c] минимум перекрасок в правильную «шахматную» 2-цветную раскраску. Решение: **сжатие цветов/координат, поддержка двух максимумов (топ-2 частых цвета по чётности клеток) за O(1), перебор прямоугольников с расширением**, O(n³), n≤400. (Динамика/структуры частот, без деревьев отрезков.)
6. **«Ночь, улица, фонарь, аптека»** — подсчёт «экономных» подмножеств отрезков-фонарей на прямой (направление влево/вправо, непрерывное покрытие без пересечений): **комбинаторное ДП по координатам** (состояния по правому концу покрытия, учёт «цепочек» с одинаковой яркостью), ответ по модулю 10⁹+7.
7. **«Марсианский рюкзак»** — для каждого префикса предметов найти минимум побитового **OR** подмножества с суммой ≥ C: **битовые маски/SOS-DP** (суммы стоимостей по подмаскам), **жадность по битам**, meet-in-the-middle; k≤19–20 бит, n до 10⁶.
8. **«Хорошие раскраски — 8»** — число k-раскрасок «граней» (дерево с заданными предками p_i<i, рёбра «активные/неактивные», q запросов-переключений): **комбинаторика раскрасок граней (хроматические полиномы циклов), ДП по дереву**, формулы от степеней вершин, удаление «висячих» вершин, **сжатие дерева до O(q) вершин**, обработка запросов.

**Важно:** в официальных разборах туров финала 2026 среди техник НЕ фигурируют DSU, теория игр/«Шпильман», потоки как самостоятельная задача (потоки/MCMF появляются только как доказательство в разборе задачи 2), отдельной «геометрии» и «строковых алгоритмов» (боры/Z-функция и т.п.) также нет — перечислено ровно то, что подтверждается условиями и разборами.

## 3. Региональный этап 2026 (профиль «Программирование»)
- Туры: **17 и 19 января 2026** (ЦПМ-новость: «Туры регионального этапа… прошли 17 и 19 января 2026»).
- Опубликованные официальные материалы (условия NEERC IFMO, разбор ЦПМК) содержат **один сквозной комплект задач 1–8** (тур 1 = задачи 1–4, тур 2 = задачи 5–8); разделения по параллелям в материалах нет.
- Темы (по официальному разбору):
  - **Тур 1 (17.01)**: 1) «Итоги олимпиады» — сортировка + префиксные суммы (сумма max(a_j−a_i,0)); 2) «Хромой король» — гамильтонов обход доски n×m с обязательной соседней парой клеток подряд — конструктив/разбор случаев чётности; 3) «Расстановки фишек» — подсчёт расстановок с ограничениями на подпрямоугольники: комбинаторика, ДП по подмножествам, включения-исключения; 4) «Прыжки по вершинам» — выпуклый вверх «маршрут» по точкам, запросы на отрезках: стек/жадность, слияние «оболочек», бинпоиск, двоичные подъёмы, divide & conquer.
  - **Тур 2 (19.01)**: 5) «Покраска бруска» — распил бруска a×b×c и подсчёт кубиков по числу окрашенных сторон (комбинаторика/простая формула по числу единичных сторон); 6) «Битовая магия» — подсчёт x∈[l,r] с x&b=b: разбор по битам (цифровая динамика/формулы), битовые операции; 7) «Скользящие окна» — минимумы на скользящих окнах по запросам: дерево отрезков, sparse table, скользящий минимум за O(n), префиксные суммы; 8) «XOR Раскраска» — раскраска массива: граф конфликтов по условию (a_x⊕b_j)≤…, хроматическое число: ДП по подмножествам, жадная раскраска с битовым сжатием, рекурсивное решение.

## 4. Прочие профили финала-2026 (кратко, с подтверждением)
- **Искусственный интеллект**: 2 тура по 5 часов (3–8 задач в туре, по «Требованиям»); по новостям — теоретический тур по математике и статистике + практический тур: обработка данных, машинное обучение, компьютерное зрение и анализ текстов (обучение моделей).
- **Информационная безопасность**: 2 соревновательных тура до 5 часов: практический CTF-тур на платформе CTFd (по новостям — устранение веб-уязвимостей на сайте, анализ исходного кода и изменение поведения программы) + **проектный тур** — защита собственного проекта по кибербезопасности в одном из направлений: Red Team (атака) или Blue Team (защита).
- **Робототехника**: 3 тура: теоретический (180 мин, 30 б.; задачи по автоматизации, электротехнике, математике), практический (подготовительный этап 180 мин/10 б. + основной 240 мин/30 б.: чертежи, пайка схем, конструирование; программирование робота на движение по траектории и перестановку «башенок» между секторами поля), проектный тур (этап техдопуска 120 мин/3 б. + основной 240 мин/27 б.; демонстрация собранных устройств на полигонах «Бизнес.Технограда»).
