# Голосовой агент АРХИМЕД (Yandex Realtime API)

Живой голосовой агент Яндекса: **микрофон → распознавание (VAD) → LLM-ответ → голос** — по
протоколу Realtime (`wss://ai.api.cloud.yandex.net/v1/realtime`). Это тот самый агент из
присланного вами примера Яндекса, с вашими данными.

## Что здесь
- `connect_test.py` — проверка подключения (без микрофона): ключ/каталог/модель/prompt.
  **Результат: соединение работает, prompt.id `aipsdas460c1epis87m1` принят** (session.created/updated).
- `realtime_agent.py` — полный агент: говорите в микрофон — агент отвечает голосом. Выход: Ctrl+C.

## Настройки (уже ваши)
- Каталог: `b1gls27f7g5coiunr5mt`
- Модель: `speech-realtime-260528/latest`
- **PROMPT_ID агента: `aipsdas460c1epis87m1`** — это НЕ ключ, а ID голосового агента-промпта
  (поэтому Яндекс не принимал его как API-ключ!)
- Ключ API — читается из `ключ_яндекса.txt` (AQVN…OCC3-a)

## Запуск (на компьютере с микрофоном и динамиками)
```
python3 голосовой_агент/realtime_agent.py
```
Зависимости установлены в `.py-libs` (aiohttp, sounddevice, yandex_ai_studio_sdk).

## Важно
- Сервис платный (тарификация Yandex SpeechKit/Realtime по вашей учётке), соединение держите коротким.
- Полный диалог требует реального микрофона — headless-проверка без микрофона невозможна
  (подключение и промпт уже подтверждены).
